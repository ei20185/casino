# オンラインカジノ風 Webアプリ（ローカル通信版）

ネットワーククラウド開発・最終課題。**WebSocket（TCPベースの通信）**を使った、複数人で遊べるカジノ風Webアプリです。

## 通信形態（課題のポイント）
| ゲーム | 通信形態 | 内容 |
|---|---|---|
| チャット | **1 : n（ブロードキャスト）** | 1人の発言を接続中の全員へ配信 |
| ポーカー卓 | **n : m（リアルタイム）** | 複数人が同じ卓で同時に対戦・状態を共有 |
| ブラックジャック | **1 : 1** | プレイヤー対ディーラー（サーバー） |

## 技術構成
- フロント：Next.js（React）
- 通信サーバー：Node.js + `ws`（WebSocket）
- 言語：JavaScript
- データ：起動中だけメモリ上に保持（架空チップ・換金なし）

## 動かし方（はじめての人向け）
1. このフォルダで、最初の1回だけ部品をダウンロード：
   ```
   npm install
   ```
2. アプリを起動（画面用サーバー＋通信サーバーが同時に立ち上がります）：
   ```
   npm run dev
   ```
3. ブラウザで次を開く：
   ```
   http://localhost:3000
   ```
4. ニックネームを入れて「入室する」。

## 複数人で遊ぶには（デモ・動画撮影向け）
- 同じPCで **別のタブやウィンドウ** をもう1つ開いて `http://localhost:3000` にアクセスし、
  別のニックネームで入室すれば、2人目・3人目として参加できます。
- ポーカーは2人以上の着席で「ラウンド開始」が押せます。
